# OUAN – กินกับอ้วน (เว็บลูกค้าใหม่ + ขวดชาไทยโต้ตอบ)

## รัน
```
npm install
npm run dev      # ทดสอบ
npm run build    # ได้โฟลเดอร์ dist/
```
Deploy `dist/` ที่เดิม (Vercel) — `admin.html`, `rider.html`, `manifest.json` อยู่ใน `public/` และถูกคัดลอกไปด้วยโดยไม่แก้ไข
ไฟล์หน้าลูกค้าเดิมสำรองไว้ที่ `legacy/index.original.html`

## เชื่อมระบบเดิม
ใช้ Apps Script ตัวเดิม (`src/utils/api.js`) เมนู/สต็อก/ร้านเปิด-ปิดมาจาก `?action=menu` ออเดอร์ส่งรูปแบบเดิมเข้าชีต `order`
สถานะอัปเดตจาก `?action=status` ทุก 15 วินาที. แอดมินและไรเดอร์ใช้ชีตเดียวกันจึงเห็นออเดอร์ทันที

## เปิดขายชาไทย / เมนูใหม่
1. ในแอดมิน แท็บเมนู เพิ่มสินค้า "ชาไทยขวด" หมวด **เครื่องดื่ม** ราคา 25 สต็อกว่าง(ไม่จำกัด) เปิดขาย
2. ถ้าชื่อมีคำว่า "ชาไทย" เว็บจะพบอัตโนมัติ หรือใส่ id ใน `src/data/products.js` (`THAI_TEA_ID`)
3. เมนูอื่นขึ้นเองเป็นการ์ดทั่วไป: เปิดขาย / "เร็วๆนี้" / หมด / ซ่อน = ตั้งค่าในแอดมินเหมือนเดิม
- แก้ราคา: ในแอดมิน (ราคาจริงคิดจากชีตเท่านั้น)
- แก้ปริมาณชา/นม: `src/data/bottleConfig.js`
- รูปสินค้า: ช่อง "รูป" ในแอดมิน (URL หรือ path ใต้ `public/`) รูปชาไทยหน้าเว็บ: `public/ouan-tea.webp`
- แพตช์หลังบ้านบันทึกสูตรลงชื่อรายการ: `backend/Code.gs.patch.md`

## ยังไม่ได้ทำ / ยังไม่ได้ทดสอบ
- ยังไม่เคยรัน build หรือเปิดเว็บ และไม่ได้ทดสอบกับ Apps Script จริง (sandbox ไม่มีเครือข่าย)
- ยังไม่มี: โค้ดส่วนลด, แผนที่ติดตามไรเดอร์, QR PromptPay, Lenis, Sharp, หน้าแยก (ใช้ปุ่มสลับมุมมองแทน Router)
- ขวดเป็น SVG วาดตามรูปทรงขวดจริง ไม่ใช่ภาพถ่ายขวดเปล่า
- สั่งไม่สำเร็จเมื่อออฟไลน์: ตะกร้าไม่หาย แต่ไม่มี outbox แบบหน้าเดิม
- ไรเดอร์ยังเห็นทุกงานที่ "กำลังจัดส่ง" (ข้อจำกัดหลังบ้านเดิม)
