# แพตช์ Code.gs (ไม่บังคับ แต่แนะนำ) — บันทึกสูตรชาไทยลงชื่อรายการ + JSON ในชีต order

หน้าเว็บส่ง `rc: "ชา/หวาน/จืด"` ต่อรายการ (เช่น "200/25/25") และใส่สูตรลงช่อง `note` ไว้แล้วด้วย
ถ้ายังไม่แพตช์ ระบบทำงานได้ปกติ (แอดมิน/ไรเดอร์เห็นสูตรในหมายเหตุ) แพตช์แล้วสูตรจะอยู่ในชื่อรายการด้วย

ใน `placeOrder` ให้แทนบรรทัดนี้:

```js
lines.push({ id: Number(r[0]), n: r[2] + (sw ? ' (' + sw + ')' : ''), q: q, p: price });
```

ด้วย:

```js
let rcTxt = '';
const rm = /^(\d{1,3})\/(\d{1,3})\/(\d{1,3})$/.exec(String(it.rc || ''));
if (rm && r[1] === 'เครื่องดื่ม') {
  const t = +rm[1], s = +rm[2], e2 = +rm[3];
  if (t < 1 || t + s + e2 > 250) return out({ ok: false, error: 'สูตรเครื่องดื่มไม่ถูกต้อง' });
  rcTxt = ' (ชา ' + t + ' / หวาน ' + s + ' / จืด ' + e2 + ' ml)';
}
lines.push({ id: Number(r[0]), n: r[2] + (sw ? ' (' + sw + ')' : '') + rcTxt, q: q, p: price, rc: rm ? rm[0] : '' });
```

แล้ว Deploy เวอร์ชันใหม่ (Manage deployments → Edit → New version)
ตรวจแล้วว่าเข้ากับ regex สรุปยอดของแอดมิน (ตัดวงเล็บท้ายชื่อ) และ `restoreStock` เดิม
เงื่อนไข: แถวชาไทยในแท็บ menu ต้องมีหมวด "เครื่องดื่ม"
